# WalkFlow MVP 정리

기준 문서: `project-goals.md`  
작성 기준일: 2026-03-31  
판정 기준: 현재 코드베이스 구현 상태 기준

## 1. MVP 정의

현재 WalkFlow의 MVP는 아래 두 조건을 최소 단위로 충족해야 한다.

1. 사용자가 측정한 대학교 근처 교차로의 보행자 신호 점등 시점을 확인할 수 있어야 한다.
2. 사용자의 현재 위치와 목적지를 기준으로, 측정한 신호등 대기 시간을 반영한 더 나은 도보 이동 판단이 가능해야 한다.

단, 2026-03-31 현재 구현 상태를 기준으로 보면 실제 앱은 아직 목표 1의 일부만 구현된 상태이며, 목표 2는 착수 전 단계에 가깝다.

## 3. 현재 구현된 MVP 범위

### A. 검색 및 이동 흐름

- [x] 사용자가 목적지를 텍스트로 입력할 수 있다.
- [x] OpenStreetMap Nominatim 기반으로 목적지 좌표를 1건 검색한다.
- [x] 검색 성공 시 지도 화면으로 이동한다.
- [x] 지도 화면에서 목적지 마커를 표시한다.

현재 한계:
- [ ] 검색 결과 다건 선택 기능 없음
- [ ] 학교 주변 측정 교차로와 검색 결과를 연결하는 로직 없음
- [ ] 경로 계산 API 연동 없음

### B. 지도 및 위치

- [x] 현재 위치 권한 요청 가능
- [x] 현재 위치를 지도에 마커로 표시 가능
- [x] 현재 위치와 목적지를 단순 선분으로 연결 가능

현재 한계:
- [ ] 실제 보행 경로 polyline 없음
- [ ] 교차로 노드 기반 경로 안내 없음
- [ ] 측정 교차로 진입/통과 판단 없음

### C. 보행자 신호 예측

- [x] 평일 시간대별 stable/transition 구간 모델링 존재
- [x] A/B 횡단보도 타입별 카운트다운 계산 가능
- [x] transition 구간에서 예측 불가 처리 가능
- [x] 지도 화면 하단에서 실시간 1초 단위 카운트다운 표시 가능

현재 한계:
- [ ] 4개 교차로 데이터 구조로 확장되지 않음
- [ ] 현재 UI는 사실상 "교차로 1번" 고정형 표시
- [ ] 주말/심야/예외 시간대 처리 미완성
- [ ] 실제 사용자의 현재 위치와 가까운 교차로를 자동 선택하지 않음

### D. 사용자 보행 속도

- [x] Zustand로 보행 속도 상태 저장 가능
- [x] 건강 앱 연동 버튼과 상태 표시 UI 존재
- [x] Expo Go 시연용 mock 연동 가능

현재 한계:
- [ ] 실제 Apple Health / Google Fit 연동 아님
- [ ] 저장된 보행 속도가 경로 계산에 아직 사용되지 않음

## 4. MVP 기준 충족 여부 판정

### 목표 1. 4개 교차로 신호 점등 시점 안내

판정: `부분 충족`

근거:
- 신호 점등 시점 예측 엔진 자체는 존재한다.
- 지도 화면에서 카운트다운도 노출된다.
- 하지만 현재 구현은 4개 교차로 전체 대상이 아니라 단일 고정형 교차로 모델에 가깝다.
- 사용자가 특정 교차로 4곳 중 하나를 선택하거나 자동 판별받는 흐름이 없다.

### 목표 2. 신호 반영 최적 길찾기

판정: `미충족`

근거:
- 목적지 검색과 지도 이동은 구현되어 있다.
- 그러나 현재 경로는 실제 길찾기 결과가 아니라 현재 위치와 목적지를 단순 직선으로 연결한다.
- 측정 교차로 포함 여부 판단, 대기 시간 반영, 대안 경로 비교, 최적 경로 추천이 모두 없다.

## 5. 현재 MVP에서 반드시 남은 항목

- [ ] 측정 대상 4개 교차로를 데이터 모델로 정식 등록
- [ ] 교차로별 위치, 횡단보도 타입, 주기 데이터 연결
- [ ] 지도에서 교차로 선택 또는 현재 위치 기반 자동 선택
- [ ] 교차로별 다음 보행 신호 시점 조회
- [ ] 실제 보행 경로 데이터 확보
- [ ] 경로 중 측정 교차로 통과 여부 판정
- [ ] 대기 시간을 포함한 경로 비용 계산
- [ ] 최적 경로 또는 최적 출발 시점 제시

## 6. 검증 메모

- TypeScript 타입체크: `pnpm exec tsc --noEmit` 통과
- 현재 상태는 "신호 예측 로직 시연 + 지도 프로토타입" 단계로 보는 것이 정확하다.
