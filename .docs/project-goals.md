# WalkFlow 프로젝트 목표 정리

## 1. 프로젝트 개요

WalkFlow는 사용자가 대학교 인근 주요 교차로의 보행자 신호 타이밍을 미리 파악하고, 그 정보를 바탕으로 목적지까지 더 효율적으로 이동할 수 있도록 돕는 서비스다.

이 프로젝트는 사용자가 직접 측정한 교차로 데이터를 기반으로 동작하며, 단순 지도 서비스가 아니라 "언제 건너는 것이 가장 유리한가"를 안내하는 것이 핵심 가치다.

## 2. 핵심 목표

### 목표 1. 보행자 신호 점등 시점 안내

사용자는 내가 측정한 대학교 근처 4곳의 교차로 보행자 신호등 데이터를 기반으로, 각 교차로에서 보행자 신호가 언제 켜지는지 확인할 수 있어야 한다.

세부 목적:
- 특정 교차로를 선택하면 다음 보행자 신호 시작 시점을 확인할 수 있어야 한다.
- 현재 시각 기준으로 남은 대기 시간을 직관적으로 확인할 수 있어야 한다.
- 측정 데이터 기반 예측이라는 점이 사용자에게 명확히 전달되어야 한다.

### 목표 2. 신호등 대기 시간을 반영한 최적 경로 안내

목표 1이 구현된 이후에는, 사용자의 현재 위치에서 목적지까지 이동하는 경로 중 내가 측정한 신호등을 건너야 하는 경우 보행자 신호 대기 시간까지 고려한 최적 경로를 안내할 수 있어야 한다.

세부 목적:
- 단순 최단거리 경로가 아니라 실제 도보 이동 효율이 높은 경로를 제안해야 한다.
- 경로상에 포함된 측정 대상 교차로의 신호 대기 시간을 반영해야 한다.
- 사용자는 "왜 이 경로가 더 유리한지"를 이해할 수 있어야 한다.

## 3. 기능 범위

### 1단계 범위
- 대학교 근처 4개 교차로 데이터 정리 및 관리
- 교차로별 보행자 신호 주기 계산 또는 예측
- 현재 시각 기준 다음 보행 신호 시작 시간 표시
- 사용자에게 남은 대기 시간 표시

### 2단계 범위
- 현재 위치와 목적지 입력
- 경로상 측정 대상 신호등 포함 여부 판단
- 신호 대기 시간까지 반영한 경로 비교
- 최적 이동 경로 추천

## 4. 핵심 사용자 가치

- 사용자는 막연히 신호를 기다리는 것이 아니라, 언제 건널 수 있는지 예측할 수 있다.
- 사용자는 신호 대기 시간을 고려해 더 빠른 이동 경로를 선택할 수 있다.
- 대학교 주변처럼 반복 이동이 많은 환경에서 체감 효율을 높일 수 있다.

## 5. 전제 조건

- 보행자 신호 예측은 사용자가 직접 측정한 4개 교차로 데이터의 정확도에 의존한다.
- 경로 탐색 기능은 측정된 교차로 데이터가 경로 계산 로직과 연결되어야 한다.
- 측정되지 않은 교차로는 일반 지도 경로 기준으로 처리하거나 예외 정책이 필요하다.

## 6. 성공 기준

- 사용자가 4개 교차로 각각의 다음 보행자 신호 시점을 확인할 수 있다.
- 사용자가 현재 시각 기준 남은 대기 시간을 이해할 수 있다.
- 출발지와 목적지를 입력했을 때, 측정한 신호등 대기 시간을 반영한 경로 추천이 가능하다.
- 추천 경로가 단순 거리 기준 경로와 어떤 차이가 있는지 설명할 수 있다.

## 7. 한 줄 정의

WalkFlow의 목표는 "대학교 주변 보행 신호 데이터를 기반으로, 사용자가 더 적게 기다리고 더 효율적으로 걸을 수 있도록 돕는 신호 예측형 길찾기 서비스"를 만드는 것이다.
